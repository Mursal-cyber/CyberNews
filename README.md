# CyberNews – Cybersecurity News Website

## Project Overview
CyberNews is an individual cybersecurity news website project. It was developed to demonstrate web development, database management, authentication, and application security concepts.

## Technologies Used
- HTML and CSS – Website structure and design
- JavaScript – Client-side functionality and news search
- Python and Flask – Backend and routing
- SQLite and Flask-SQLAlchemy – Database management
- Werkzeug – Secure password hashing
- GitHub – Source code repository

## Main Features
- Cybersecurity news dashboard
- News articles organized by categories
- Search functionality
- Individual article pages
- User registration and login
- Session-based authentication
- Role-based administrative access
- Admin dashboard for adding and deleting articles
- SQLite database for storing articles and user accounts
- Password hashing for secure credential storage

## Project Development
The project started with an AI-generated prototype using Lovable. The website was then rebuilt using HTML, CSS, JavaScript, Flask, and SQLite.

## How to Run Locally
1. Install Python.
2. Install dependencies: `pip install flask flask-sqlalchemy`
3. Run the application: `python app.py`
4. Open `http://127.0.0.1:5000` in a browser.
